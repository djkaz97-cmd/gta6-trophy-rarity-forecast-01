Forecasts every Grand Theft Auto VI PlayStation 5 trophy's Exophase earn rate at the case target as five quantiles (5/25/50/75/95%), scored by mean pinball loss on the logit scale. `main.py` (Python 3.13, standard library only, no network, deterministic, ~0.2 s per case) fits a recency-weighted logit trend against ln(1+hours since release), extrapolates it with horizon damping, and builds the spread from realized volatility over all reads (quiet reads included, so Exophase's refresh jumps are diluted honestly), plus trend uncertainty and a first-refresh allowance while the tracked-player count has never moved.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
